# The Christmas We Share

The release ZIP contains the complete editable project, database migrations, and tests. Cloudflare Workers Builds unpacks it before deployment.

- Build command: `unzip -oq The-Christmas-We-Share-release.zip`
- Deploy command: `npx wrangler deploy`
- Production branch: `main`

Set the database settings as Cloudflare Worker runtime variables and secrets. The archive contains a configuration example.
